# Changelog

Every change to this methodology lands on `main`, almost always as a merged
pull request. The list below is rebuilt from `main`'s history each time the
site deploys, newest first. Each entry links to its pull request, or to the
commit when the change was pushed directly.

GitHub keeps the full record too:

- [Merged pull requests](https://github.com/tangentcode/methodology/pulls?q=is%3Apr+is%3Amerged+sort%3Aupdated-desc), with their discussion and reviews
- [Commit history of `main`](https://github.com/tangentcode/methodology/commits/main)
